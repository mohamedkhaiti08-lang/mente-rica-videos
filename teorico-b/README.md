# Teórico B en 30s

- `plantilla/voz.py` – voz con Kokoro (por defecto `ef_dora`, mujer, español). Admite `"gaps"` para silencios (cuenta atrás).
- `plantilla/motor_b.py` – motor de vídeo: estilo azul señal + amarillo, imágenes dibujadas (coches, baliza V-16, autovía cenital, semáforo, señales, BOE…), subtítulos karaoke y efectos de sonido.
- `ejemplos/v16` (¿APROBARÍAS?), `ejemplos/pasillo` (ESTO HA CAMBIADO), `ejemplos/cruce` (¿QUIÉN PASA PRIMERO?, vis cruce), `ejemplos/neumatico` (CIFRA CLAVE, vis tyre), `ejemplos/puntos` (ERROR DE NOVATO, vis puntos) `ejemplos/ciclista` (POV, vis bike + speedo), `ejemplos/glorieta` (¿QUIÉN PASA PRIMERO? parte 2, vis glorieta) `ejemplos/alcohol` (TRAMPAS DEL EXAMEN, vis alcohol), `ejemplos/senal-vacia` (SEÑAL MISTERIOSA, vis senal) `ejemplos/cruce-tranvia` (¿QUIÉN PASA PRIMERO? parte 4, cruce con tranvía), `ejemplos/tunel` (TRAMPAS DEL EXAMEN, vis tunel) `ejemplos/peaton-giro` (¿QUIÉN PASA PRIMERO?, vis giro con peatón), `ejemplos/niebla` (¿APROBARÍAS?, vis niebla con antinieblas) `ejemplos/cuesta` (¿QUIÉN PASA PRIMERO? parte 7, vis cuesta), `ejemplos/deslumbramiento` (POV, vis noche: carretera de noche, largas/cortas) y `ejemplos/puente` (¿QUIÉN PASA PRIMERO? parte 9, vis puente con señal R-5), `ejemplos/cafe` (MITO O VERDAD, vis cafe: bar, café, trucos tachados, reloj de arena) y `ejemplos/bus-parada` (¿QUIÉN PASA PRIMERO? parte 10, vis bus + buslaw: parada en isleta), `ejemplos/marcha-atras` (¿APROBARÍAS?, vis marcha: cámara de marcha atrás, cinta métrica, cruce, autovía) y `ejemplos/garaje` (¿QUIÉN PASA PRIMERO? parte 11, vis garaje + garlaw + regla), `ejemplos/mercancias` (SEÑAL MISTERIOSA, vis merc: calle lateral, R-106/R-107, furgoneta) y `ejemplos/plataforma-unica` (¿QUIÉN PASA PRIMERO? parte 12, vis plataforma + platlaw + perfil) – guion.json + config.json de referencia.
